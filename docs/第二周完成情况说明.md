## 三、具体成果

### 1. 价格查询 API

- 新增 `PriceData` 实体（含 `region` 地区字段）
- 新增 `PriceDataMapper` / `PriceDataService` / `PriceDataController` 完整分层
- `GET /api/price/query`：支持 `startDate`、`endDate`、`goodsId` 参数组合筛选
- 与既有 `Goods` 查询接口共同构成后端数据查询能力

### 2. 数据入库接口

- 新增 `POST /api/price/import`：支持批量入库，供爬虫调用
- 数据库 `price_data` 表新增 `region` 字段，唯一约束调整为 `(goods_id, price_date, region)`，实现"同商品同地区同日"去重

### 3. 爬虫脚本（crawler/crawler.py）

- 数据源：中国价格信息网（chinaprice.cn）周报
- 完整处理链路：
  - **抓取**：requests 抓取周报页面（已禁用本地代理避免 SSL 干扰）
  - **解析**：BeautifulSoup + lxml 解析表格
  - **清洗**：`NAME_MAP` 名称归一（如"洋葱(元葱)"→"洋葱"）、正则提取日期、价格转 float
  - **单位统一**：统一折算为"元 / 公斤"（原数据为元/斤时 ×2）
  - **去重**：按 `(goods_id, price_date, region)` 去重
  - **入库**：调用 `POST /api/price/import`
- 实际抓取结果：**30 个品种、624 条真实价格数据成功入库**

### 4. 定时任务（crawler/scheduler.py）

- 基于 `schedule` 库，可按天 / 周定时触发爬虫
- 预留了异常处理与日志输出位置

## 四、遇到的问题与解决

| 问题 | 解决 |
|------|------|
| MySQL 报 `Public Key Retrieval is not allowed` | JDBC URL 增加 `allowPublicKeyRetrieval=true` |
| 后端端口被占用（63070 干扰） | `application.yml` 显式配置 `server.port: 8080` |
| 唯一约束缺 region 导致 30 条覆盖 624 条 | 唯一约束改为 `(goods_id, price_date, region)` |
| 本地代理（127.0.0.1:58076）干扰爬虫 SSL 握手 | 脚本顶部禁用代理 `NO_PROXY='*'` |
