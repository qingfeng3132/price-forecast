## 四、MySQL 配置

| 项 | 值 |
|----|-----|
| 版本 | 8.4.9 LTS |
| 程序路径 | `C:\Program Files\MySQL\MySQL Server 8.4\` |
| 数据目录 | `D:\dev\mysql\data\` |
| 配置文件 | `D:\dev\mysql\my.ini` |
| 启动脚本 | `D:\dev\mysql\start-mysql.bat` |
| 停止脚本 | `D:\dev\mysql\stop-mysql.bat` |
| 端口 | 3306 |
| root 用户 | root |
| root 密码 | `Price@2026` |
| 项目数据库 | `price_forecast`（utf8mb4） |

### 启动方式

双击 `D:\dev\mysql\start-mysql.bat`，弹出黑色窗口后**不要关闭**（关闭即停止 MySQL）。停止用 `stop-mysql.bat`。

> 说明：MySQL 未安装为 Windows 开机自启服务（安装服务需管理员权限），采用脚本启动。

### 初始化命令

```bash
mysql -u root -p --default-character-set=utf8mb4 price_forecast < docs/sql/schema.sql
```

## 十、遗留事项

1. 系统残留两个失效 MySQL 服务（`mysql8`、`MySQL80`，指向已删除的旧 MySQL）。清理命令（管理员 PowerShell）：
   ```powershell
   sc.exe delete mysql8
   sc.exe delete MySQL80
   ```
2. 旧 MySQL 8.0 数据目录 `C:\ProgramData\MySQL\MySQL Server 8.0\Data` 未迁移，如需旧数据再处理。
